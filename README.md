# BharatSkills Foundation (Next.js)

Modern, responsive, SEO-friendly website for BharatSkills Foundation built using Next.js (App Router), React, and CSS3.

## Tech Stack
- Next.js 14
- React 18
- CSS3

## Pages
- Home (`/`)
- About (`/about`)
- Courses (`/courses`)
- Workflow (`/workflow`)
- Career Support (`/career-support`)
- Contact (`/contact`)

## Features
- Sticky navbar + mobile hamburger menu
- Parallax hero section
- Scroll reveal animations
- Animated counters
- Testimonial slider
- FAQ
- Dark mode toggle
- SEO metadata and semantic headings

## Run Locally
```bash
npm install
npm run dev
```
